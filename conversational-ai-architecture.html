The Hybrid Routing Principle

The Conversation Router decides per-turn whether to use a deterministic dialog flow (for state-changing operations like plan upgrades, payments, profile updates) or free-form LLM (for informational queries like "what's my bill?" or "explain data rollover"). This gives you the reliability of state machines where it matters and the flexibility of LLM where it shines.

New Components for Conversational AI

Six new Java services that add structured dialog management to the existing prototype.

1. NLU Engine (Intent + Entity)

Classifies user intent before the LLM sees the message. Extracts structured entities (amounts, dates, plan names). Uses a lightweight classifier (logistic regression or small BERT) for speed, falling back to LLM for ambiguous cases.

DJL (Deep Java Library)ONNX RuntimeBERT-tiny

2. Dialog Manager (State Machine)

Manages conversation state for multi-turn flows. Each flow (billing inquiry, plan change, complaint) is a finite state machine with defined transitions, required slots, and confirmation gates. Persisted in Redis per session.

Spring StatemachineRedis PersistenceYAML Flow Defs

3. Slot Filling Engine

Tracks which information has been collected and what's still needed. Generates targeted prompts for missing slots. Validates slot values against business rules (e.g., plan code must exist, amount must be positive).

Custom JavaValidation APIEntity Resolution

4. Sentiment Analyzer

Detects customer frustration, anger, or confusion in real-time. Triggers tone adjustments ("I understand this is frustrating...") or escalation to human agents when sentiment drops below threshold.

DJL + DistilBERTSliding WindowEscalation Rules

5. Conversation Router

The brain that decides per-turn: use a structured dialog flow (deterministic, safe for mutations) or free-form LLM (flexible, great for queries). Routes based on detected intent + current dialog state.

Rule EngineIntent → Flow MapFallback Chain

6. Agent Handoff Manager

When the bot can't resolve (3+ failed attempts, negative sentiment, explicit request), it prepares a structured context summary and transfers to a human agent via queue with full conversation history.

SQS / RabbitMQContext SummarizerAgent Dashboard API

Conversation Transcript

Customer: I want to upgrade my plan

→ NLU: intent=PLAN_CHANGE | Router: STRUCTURED_FLOW | State: INIT → COLLECT

Bot: I'd be happy to help you upgrade! You're currently on the Postpaid ₹499 plan. Which plan would you like to switch to? We have Postpaid ₹999 (150GB data, unlimited calls) and Fiber ₹799 (200GB).

Customer: The 999 one

→ NLU: entity=POST999 | Slot filled: target_plan=POST999 | Missing: timing | State: COLLECT

Bot: Great choice! The Postpaid ₹999 gives you 150GB data and unlimited calls. Should the change take effect immediately or from your next billing cycle (April 1)?

Customer: Next cycle

→ Entity: timing=NEXT_CYCLE | All slots filled | State: COLLECT → VALIDATE → CONFIRM

Bot: Here's a summary of your plan change:
• Current: Postpaid ₹499/month
• New: Postpaid ₹999/month (150GB, unlimited calls)
• Effective: 01 Apr 2026
• Monthly increase: ₹500

Shall I proceed with this upgrade? (Yes/No)

Customer: Yes, go ahead

→ Confirmation: YES | State: CONFIRM → EXECUTE → COMPLETE | Tool: upgrade_plan(POST999, NEXT_CYCLE)

Bot: Done! Your plan has been upgraded to Postpaid ₹999. It will take effect on 01 Apr 2026. You'll receive a confirmation SMS shortly. Is there anything else I can help with?

Implementation Strategy

Key Java classes and how they integrate with the existing Spring Boot prototype.

Integration Point

The Conversational AI layer is inserted between the controllers and the AI orchestrator. The ChatController now calls ConversationRouter instead of calling AiOrchestratorService directly. The router decides whether to use a structured dialog flow or free-form LLM per turn.

Core Integration Flow

// ChatController (modified)
@PostMapping("/message")
public ResponseEntity<ChatResponse> chat(@RequestBody ChatRequest req) {
// Step 1: NLU extracts intent + entities NluResult nlu = nluEngine.analyze(req.message());
// Step 2: Sentiment check SentimentScore sentiment = sentimentAnalyzer.analyze(req.message());
// Step 3: Router decides: structured flow vs free-form LLM return conversationRouter.route(sessionId, nlu, sentiment, req.message()); }
